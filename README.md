One kind, funny fortune for a houseplant, in a single line of 96 characters — written for the plant on the windowsill, in the cadence of a prediction:

> A tall stranger is coming to your window — it is only the sun, and it has missed you all winter.

Entry for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on make.fun: a program that writes the fortune to `/output/entry.txt`, where a gardener-judge compares it two at a time against other fortunes.

## Run it

```sh
node main.ts
```

`main.ts` validates the fortune (single line, 1–120 characters, no leading/trailing whitespace) and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), then reads it back to confirm the file matches exactly.
